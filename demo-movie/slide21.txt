We don’t have the real My Self Serve application, so we will demonstrate using a test harness that has BC Services Card login,
 and an interface to call the API to get the PHN.

Harley uses a test account to first login.

He then calls the new API endpoint from the Provincial Client Registry to get the Patient Health Number.

This is a very specific small piece of data, but the pattern of using SDX, Common SSO, and Scopes to control access
is the same as the API endpoints grow and more authoritative data is shared.
