# API Services Portal Release 3.0.15

The API Services Portal has been updated ahead of British Columbia's switch to
year-round UTC-7 on November 1, 2026. This release also includes the
changes from 3.0.14, which was not deployed on its own.

## Updates

- **BC time zone support** - The Portal now uses updated time zone data, so
  dates and times reflect BC staying on UTC-7 year-round from November 1, 2026.
- **Activity times in BC time** - Times on the Activity page are now
  shown in BC time.

### Updates from 3.0.14

- **Copyright page** - The copyright notice now shows the current year, and
  outdated contact details have been removed.
