# API Services Portal Release 3.1.0

API Providers can now get contact details for the consumers of their APIs.

## Updates

- **Consumer contact details** - API Providers can get their consumers'
  email addresses to contact them about API changes, deprecations, or job
  completion. Two new endpoints return the consumer access and consumer request
  reports for a Gateway as JSON, with application owner and requestor emails.
  See
  [Get consumer contact details via API](/how-to/api-access.md#get-consumer-contact-details-via-api).
- **Emails in the gateway report** - The **Export Gateway Report** spreadsheet
  now includes an **Application Owner Email** column on the **Consumer Access
  (Products)** sheet and a **Requestor Email** column on the **Consumer
  Requests** sheet.
