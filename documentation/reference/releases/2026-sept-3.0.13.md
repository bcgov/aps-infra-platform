# API Services Portal Release 3.0.13

The API Services Portal has been updated with a new feature.

## Features

- **Self-issuing credentials** - API Providers can issue and regenerate
  consumer credentials for Product Environments they manage, without an
  Access Request or approval queue.

  This is intended for programmatic provisioning from an onboarding system or
  CI/CD pipeline. The Credential Issuer API supports Kong API Key and Client
  Credentials flows, and access is enabled immediately.

  Instructions are available in
  [Issue Consumer Credentials via API](/how-to/self-issue-credentials.md).
